Doubly Linked List – Practice Project

This project is a simple implementation of a Doubly Linked List (DLL) in C++ built for practice and understanding data structures. You’re welcome to use, modify, or extend it however you like!

Features

Create a new list

Insert nodes at the beginning, end, or specific position

Delete nodes from any position

Traverse the list forward and backward

Display list contents


Why Doubly Linked Lists?

Unlike singly linked lists, DLLs allow two-way traversal thanks to both next and prev pointers. This makes operations like deletion and reverse traversal more efficient.

Technologies Used

C++ – Core logic and structure

Object-Oriented Programming – Class-based design


How to Run

1. Clone or download the repository.


2. Open in any C++ IDE or terminal.


3. Compile the code:

g++ doubly_linked_list.cpp -o dll
./dll


4. Follow the menu options to interact with the list.
